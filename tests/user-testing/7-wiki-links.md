# 7) Wiki Links (`[[` Popup)

- Click the clear button and refresh each page so we are starting fresh.
- Open two browser tabs on the collab page with the same doc id and different users.
- In the active page, type `[[` and then type `Fi` one key at a time.
- Confirm the wiki-link popup opens and shows matching note suggestions.
- Press `Enter` to select the highlighted wiki-link suggestion.
- Wait for sync to propagate to the second tab.
- Take screenshots of both pages.
- Compare output. Are both editors showing the same wiki-link result?
- Result is PASS only if:
  - no runtime errors
  - popup opens and selection works
  - both tabs render equivalent content
